Research interpretation

For 1,000 and 10,000 transactions, the simpler Python baseline had lower mean execution time. At 100,000 transactions, the Pandas-based artifact had lower mean execution time. This indicates a workload-dependent trade-off, not universal superiority.

Both approaches passed equivalence checks for category, store and daily sales summaries. The baseline represents a sequential Python implementation rather than every conventional ETL system.
